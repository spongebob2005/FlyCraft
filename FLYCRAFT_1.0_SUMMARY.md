## 🎮 Ready-to-Use Features

### Animations (Press Keys)
| Key | Animation |
|-----|-----------|
| **V** | Wave greeting |
| **C** | Hand clapping |
| **B** | Full body dance |
| **X** | Spin rotation |
| **Z** | Jump boost |

### Flight Controls
- **Forward** - Accelerate
- **Sneak** - Dive
- **Jump** - Ascend
- **Glide** - Smooth flight

### Visual Effects
- Speed lines in jet mode
- Vignette overlay effect
- G-force blur at high speeds
- 6 particle effect types

## 🔧 Build & Deployment

### Build Project
```bash
./gradlew clean build
```
**Output:** `build/libs/flycraft-1.0.jar`

### Run in Development
```bash
./gradlew runClient
```

### Key Configuration
- All settings in `gradle.properties`
- Java 21 LTS (optimized but Java 8+ compatible)
- Forge 47.4.10 for Minecraft 1.20.1
